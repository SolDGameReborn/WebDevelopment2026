Web Development

HTML

An HTML stands for HyperText Markup Language. It is the standard code used to structure and organize the content of a web page. An example of what it does is that it tells a web browser like Google Chrome what content there is like headings, paragraphs, etc.

CSS

A CSS stands for Cascading Style Sheets. It is a standard style sheet language used to determine the visual layout, design, and presentation of a website. CSS is considered one of the three cornerstone technologies that power the World Wide Web.

JavaScript

JavaScript is a lightweight, interpreted programming language that serves as one of the core technologies of the World Wide Web. This is alongside CSS and HTML. JavaScript enables dynamic activity, where it allows developers to make features like animated graphics, interactive maps, etc.

JQuery

JQuery is a fast, lightweight, and open-source JavaScript library designed to simplify HTML DOM tree transversal, manipulation, event handling, animation, and Ajax interactions. JQuery wraps common web development tasks into simple methods which can be called in one line of code. It follows the motto: Write less, do more.
